Minor updates specification v1.0 to v1.1

The modifications outlined below are deemed minor, as the XLUM format is not widely adopted; they are necessary to mature the format. After, any substantial revisions will necessitate a major version increment.

  • Update formatVersion to recent version
  • Add version information to XSD schema
  • Remove 'camera' and 'spectrometer' from the specification as recordType, this did not make sense; update XSD scheme accordingly.
  • Update Fig. 3.1 to align figure better with specification
  • xValues and yValues allow double instead of signed integer values (specification and XSD schema)
  • Change NA to 0 for xValues and yValues
  • Correct type mismatch to align specification with XSD schema
  • Typo correction and minor clarifications
